Rebalancer 개인정보처리방침

시행일: 2026년 11월 7일

Rebalancer는 개인이 자신의 주식 계좌 비중을 관리하기 위해 만든 비공개 도구입니다. 이 앱은 운영자 본인과 가족만 사용하며, 일반에 서비스하지 않습니다.

1. 접근하는 정보

  • 구글 드라이브: 이 앱이 만든 Rebalancer 폴더 안의 파일(portfolio.json, prices.json)만 읽고 씁니다.
  • 구글 계정 이메일 주소: 로그인한 계정을 화면에 표시하는 데에만 사용합니다.

2. 정보의 보관과 전송

  • 모든 데이터는 사용자 본인의 구글 드라이브에만 저장됩니다. 별도의 서버나 데이터베이스에 수집·보관하지 않습니다.
  • 어떤 정보도 제3자에게 판매하거나 제공하지 않으며, 광고나 분석 목적으로 사용하지 않습니다.
  • 시세 조회를 위해 공개 시세 서비스(Yahoo Finance, 네이버 금융)에 종목 코드만 전송합니다. 계좌 정보는 전송하지 않습니다.

3. 권한 철회와 삭제

  • 구글 계정 설정의 서드 파티 앱 및 서비스에서 언제든 이 앱의 접근 권한을 해제할 수 있습니다.
  • 구글 드라이브의 Rebalancer 폴더를 삭제하면 모든 데이터가 삭제됩니다.

4. 구글 API 서비스 사용자 데이터 정책 준수

이 앱이 구글 API로부터 받은 정보의 사용과 전송은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 따릅니다.
